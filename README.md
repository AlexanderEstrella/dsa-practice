# DSA Practice (JavaScript)

Daily Data Structures & Algorithms practice in **JavaScript** — focused on writing clean solutions, explaining tradeoffs, and building repeatable problem-solving patterns (not just “getting accepted”).

## What’s inside

- **Solving patterns** (ex: two pointers, sliding window, hash map, recursion, stack/queue, tree/graph basics)
- **Readable implementations** in vanilla JS (no TypeScript)
- **Notes + learnings** alongside code to document reasoning, pitfalls, and optimizations
- Emphasis on:
  - Correctness first
  - Time/space complexity awareness
  - Edge cases + input validation
  - Clean function signatures

## Repo structure

Right now I’m starting with a single file while I build momentum:

- `Index.js` — current solutions + notes

As it grows, I’ll expand into folders like:
- `arrays/`, `strings/`, `hashmaps/`, `linked-lists/`, `trees/`, `graphs/`, etc.

## How I practice

For each problem, I aim to include:

- ✅ Problem goal (1–2 lines)
- ✅ Approach
- ✅ Big-O time + space
- ✅ Edge cases
- ✅ Final code
